# Project Data

This folder contains synthetic datasets used by the University Phishing Awareness Programme Dashboard.

## Data Principles

- All records are fictional and intended for demonstration.
- No real student or staff personal data is included.
- Dataset fields should follow the definitions documented in `docs/data-dictionary.md`.
- Data quality should be checked before calculations or visualisations are produced.

## Planned Datasets

- Project task tracker
- Project milestones
- Budget tracking
- Aggregated cybersecurity awareness metrics

## Usage

These datasets will be used to practise data import, transformation, validation, and dashboard development in Microsoft Power BI Desktop.
