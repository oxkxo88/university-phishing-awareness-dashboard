# Project Data

This folder contains synthetic datasets for the University Phishing Awareness Programme Dashboard.

## Available Datasets

| File | Purpose | Main Use |
|---|---|---|
| `project-tasks.csv` | Project task details, deadlines, priorities, and progress | Project delivery dashboard |
| `awareness-metrics.csv` | Aggregated training and simulated phishing metrics | Cybersecurity awareness dashboard |

## Data Quality and Privacy

- All records and figures are fictional.
- No real student or staff personal data is included.
- Task completion values are numeric proportions: `1` represents 100%, `0.6` represents 60%, and `0` represents 0%.
- Dates use the `YYYY-MM-DD` format in `project-tasks.csv` and the `YYYY-MM` format in `awareness-metrics.csv`.
- Validate data types and calculations before using the datasets in reports.

## Intended Use

These datasets are designed for practising data import, transformation, validation, KPI calculations, and dashboard development in Microsoft Power BI Desktop.
