# Project Charter

## 1. Project Name

University Phishing Awareness Programme Dashboard

## 2. Background

Universities rely on digital communication for teaching, administration, and collaboration. Phishing awareness programmes can help staff and students recognise suspicious messages and report potential threats.

This project simulates the planning, delivery, and monitoring of such a programme at a fictional university.

## 3. Project Objectives

- Plan a fictional 12-week awareness programme.
- Track tasks, milestones, risks, and budget.
- Use Excel VBA to validate project data.
- Develop a Power BI dashboard to communicate project performance.
- Demonstrate project management, data analysis, and cybersecurity awareness skills.

## 4. Scope

**Included:**
- Project task and milestone tracking.
- Risk and issue management.
- Budget monitoring using synthetic figures.
- Aggregated training completion and awareness metrics.
- Automated data validation and dashboard reporting.

**Excluded:**
- Testing real university systems.
- Sending real phishing simulations.
- Collecting personal information about students or staff.
- Accessing or analysing real institutional security records.

## 5. Stakeholders

- Project Manager
- Cybersecurity Lead
- Awareness Training Lead
- Communications Lead
- University Management (simulated)

## 6. Success Criteria

The project will be evaluated against illustrative targets:

- Complete the planned programme within 12 weeks.
- Achieve at least 85% training completion.
- Improve the simulated awareness assessment score by 15 percentage points.
- Deliver at least 90% of milestones on time.
- Keep budget variance within 5%.

These are proposed targets for the simulation, not real-world results.

## 7. Assumptions and Constraints

- All data will be synthetic.
- The project will use desktop Excel and Power BI.
- The dashboard will report aggregate metrics rather than individual behaviour.
- The project is an independent learning and portfolio exercise.

## 8. Deliverables

- Excel project tracker and VBA automation.
- Project documentation and risk register.
- Synthetic datasets.
- Power BI dashboard.
- Test plan and project closure report.
