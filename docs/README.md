# Project Documentation

This folder contains the planning documents, project management artefacts, testing documentation and dashboard screenshots for the **University Phishing Awareness Programme Dashboard**.

The project uses synthetic data to demonstrate how cybersecurity awareness initiatives can be planned, monitored and evaluated using Excel VBA, Power BI and project management techniques.

## Documentation

| File | Description |
|---|---|
| `project-charter.md` | Defines the project purpose, objectives, scope and deliverables. |
| `requirements.md` | Documents the project requirements and intended functionality. |
| `work-breakdown-structure.md` | Breaks the project into manageable deliverables and work packages. |
| `test-plan.md` | Describes the testing approach and validation activities. |
| `risk-register.csv` | Records project risks, their potential impact and planned responses. |
| `raci-matrix.csv` | Defines project responsibilities using the RACI framework. |

## Related Datasets

The synthetic datasets used by the project are stored in the repository's `data/` folder:

- `project-tasks.csv` — project tasks, owners, deadlines, priorities and progress.
- `awareness-metrics.csv` — staff training and phishing simulation metrics by department and reporting period.
- `milestones.csv` — project milestones and planned delivery dates.
- `budget.csv` — illustrative project budget estimates and allocations.

## Data Disclaimer

All data is synthetic and intended for portfolio demonstration and educational purposes only. It does not represent actual university staff, financial information or cybersecurity performance.
